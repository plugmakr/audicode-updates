# AudiCode updates

Public update feed of the LoopKit Updater only: `loopkit-updater/latest.json` (its installers are on the
`loopkit-updater-v<version>` releases) and `catalog.json`, the product list the Updater shows.

Orbik, ORBIK Studio, Orbik Player and PatchCraft are not published here. Their installers are delivered behind the
buyer's LoopKit sign-in (`https://loopkit.com/functions/v1/productUpdate`), which the LoopKit Updater and the plug-ins use.
